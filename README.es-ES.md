# Video2Discord

Comprime fácilmente videos grandes a cualquier tamaño con [**Video2Discord**](https://github.com/ZoontS/Video2Discord).

## Cómo usarlo
### Windows
1. [***Descarga la última versión aquí***](https://github.com/ZoontS/Video2Discord/releases/latest)
2. Descomprime el archivo zip.
3. Ejecuta Video2Discord.exe.
4. Selecciona los vídeos que quieras comprimir.
5. Espera a que termine el proceso.

### Linux
Por ahora, puedes usar directamente `Video2Discord.py`. Necesitarás tener FFmpeg y Python instalados.

¡El lanzamiento en PyPI llegará pronto!

### Uso avanzado
Video2Discord también puede utilizarse como una herramienta de línea de comandos. Ejecútalo con `--help` para ver las opciones disponibles.
